## Field Reference

- **Auth levels in use:** `public`, `admin` (single admin account, session validated server-side in `src/lib/admin.ts`)
- **Status progression:** `planned` → `built` → `verified`
- **Generated routes:** `/robots.txt`, `/sitemap.xml`, `/icon.svg`
- **`src/proxy.ts`** redirects `/admin` to `/login` when no session cookie exists. It is a UX redirect only, not an authorization check.

## Notes

- Visitors never need an account. Better Auth exists only for the admin dashboard.
- Image files are processed entirely in the browser and never reach any API route.
- V2 CLI/MCP ships separately as `@imagesmith/cli`; no CLI routes live in this repo.
